# SoundCloud attribution asset

`soundcloud-logo-white.webp` is the unmodified white horizontal logo downloaded
on 2026-10-08 from the current [SoundCloud Media Kit](https://community.soundcloud.com/company/media-kit),
which is linked by the [developer branding guidelines](https://developers.soundcloud.com/docs/api/buttons-logos).

Original asset:
<https://cdn.prod.website-files.com/62a0a0168756b795debc65bc/69ef2abb874551e8c75433a2_Horizontal%20White%20(transparent)-download.webp>

The renderer uses it on `#121212`, preserves its aspect ratio and image data,
and displays it at 64px wide (above the stated 30px minimum). Clicking the
attribution opens the current track through the validated main-process command.
SoundCloud retains all rights to its logo; its use is subject to the linked
branding guidelines and API terms.

The developer guide's older PNG download URLs still contain the previous logo;
this asset comes from the current Media Kit's white horizontal logo download.
