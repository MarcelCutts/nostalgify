## Appendix D: method and coverage

Stage 1, per PR: six independent review lenses (correctness, security, tests and verification, narrative accuracy, clarity and cleanliness, standards and prior art), each with internet access and required to cite current Electron, SoundCloud, hls.js and Node documentation for any claim about external behaviour, followed by a merge pass. The collection pass used seven lenses (stack narrative, terminology, docs at the merged state, commit hygiene, cross-PR code coherence, PR presentation, current practice and prior art). Stage 2: adversarial verification by independent refuters (two per high-severity finding with different briefs, one per batch of three medium findings, one per batch of six low findings; nits unverified), then synthesis. A finding survives only if at most half of its refuters reject it. The planned completeness-critic pass did not run (it failed on an account usage limit), so coverage is what the lenses chose to examine.
